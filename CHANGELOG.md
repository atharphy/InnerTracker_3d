# Changelog

## 0.2.0 — Standalone distribution

- Package the 0.1.33 dashboard as a clone-and-run Grafana project.
- Add Docker Compose with Prometheus and fictional demo telemetry.
- Include a prebuilt plugin, native installer helpers and full setup documentation.
- Keep 3,892 nominal module positions, two-sided Dee geometry, individual-Dee
  visibility, support-free rear-image viewing, installed filtering and portcard mapping.
- Accept `module_id` / `chip_efuse` as well as legacy CSV label names.
- Disable navigation to an external chip-details dashboard until its UID is configured.
